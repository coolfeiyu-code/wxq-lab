# 万象实战 1.0.0 使用说明

这是《王者万象棋》的赛前查询和赛后记录工具。它不读取游戏画面，也不替你操作。

## 在这台电脑上打开

源码目录是 `wxq-lab`。

```text
cd ui && npm ci
cd .. && npm test
npm run build
npm run ui
```

浏览器打开 http://localhost:5177/#/assist

顶栏「实战」进入开局推荐。手册、本局追踪、个人战绩和数据状态在同一组页面里。

悬浮窗页面是 http://localhost:5177/#/overlay 。正式窗口在同步目录：

`万象棋AI实战助手/启动悬浮窗.bat`

它启动 `app/windows/WxqOverlay.exe`。程序自带 .NET 运行时，不需要再装 .NET。需要系统里已有 Edge WebView2。窗口标题是「万象实战 1.0.0」，在本机 5188 端口打开上面的页面。这台电脑上窗口能画出推荐页。个别棋手名仍可能贴着右缘，把窗口拖宽即可。

## 一局怎么记

1. 选 3 名特邀棋手。
2. 选本局禁用的阵营。禁用命中的英雄不会出现在推荐里。
3. 看排序分、样本和来源。样本不足 1000 的阵容不进主排序。
4. 采用一套后，在「本局」里补血量、能量、英雄和你真正做过的选择。
5. 结束时名次只能选第 1 到第 6 名。空着就保持未知。
6. 本地复盘只根据写下的内容。没写的操作不会被编出来。

撤销和重做在本局页。悬浮窗里按 1、2、3 切换推荐、手册、记录，Ctrl+Z 撤销。

## 战绩放在哪

文件在极空间同步目录：

`万象棋AI实战助手/user-data/matches.json`

备份在同目录的 `backups/`。不要两台电脑同时改这份文件。另一台如果正开着程序，这边保存会失败，原文件不动。

社区统计和个人战绩分开。个人第一名率只算已结束、且名次是 1 到 6 的局。

## 数据是哪天的

打开「数据」页。1.0.0 使用仓库里的 `data/meta/2026-10-12`。卡牌原文是 2026-09-14 的提取。两边日期不同，技能描述不能当成现行版本。

更新统计用顶栏「更新数据」。失败时保留上一份快照。

## 成品目录

`万象棋AI实战助手/` 给别的电脑直接用。里面有网页成品、悬浮窗程序、2026-10-12 的必要数据和这份说明。源码和 Git 历史仍以 GitHub 仓库为准。

另一台电脑要先等极空间同步完成，再双击 `启动悬浮窗.bat`。那台电脑也要有 Edge WebView2。第二台是否真能打开，这次没有验证。

开发缓存的排除写在同步根目录的 `.stignore`。规则已经加上，极空间客户端有没有重新加载，这次没有在客户端界面里确认。

不要两台电脑同时开着悬浮窗或 `npm run ui` 去改同一份战绩。锁大约 2 分钟。正常关闭会放开锁。强制结束进程时，锁可能还要等过期。
